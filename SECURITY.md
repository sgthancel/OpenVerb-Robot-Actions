# Security Policy

## Supported Versions

Only the latest version of OpenVerb Town is currently supported for security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please open a GitHub Issue with the label "security". We take all security vulnerabilities seriously and will work to address them as quickly as possible.

Please do not report security vulnerabilities through public social media or other public channels.
